Features

Everything that matters, one tap away.

A pinned button on the Control Strip opens a bar with the widgets you choose. No sudo, no weight, no Dock icon.

🌡️

Temperature and fan

CPU and GPU with colours by range, fan speed and history sparklines.

⚡

Frequency and usage

CPU and GPU frequency, plus usage per efficiency and performance cores, read without sudo.

🧠

Memory, network and disk

RAM, memory pressure, download and upload, SSD reads and writes, and the heaviest processes.

↔️

Scrollable bar

Too many widgets? The bar scrolls with your finger. Drag whole rows to reorder them in Preferences.

🔔

Alerts

A notification when the temperature passes your limit, with a cool-down so it never nags.

✦

Claude mode

Session, weekly limit, credit and service status, with the little pixel robot on the Control Strip.

Screens

A full panel in the menu bar.

Click the icon to see every metric with min, average and max, plus your Claude usage.

Claude mode

Your Claude limits, without opening anything.

A second button, separate from the Mac mode. Minimised, it is just the little robot. Tap it to open the full bar.

  • 5-hour session and weekly limit with a bar and the time until reset.
  • Monthly extra credit and weekly usage by source: Claude Code, chats and Cowork.
  • Tokens today by model, live activity and service status.
  • Automatic: it uses the login Claude Code already has on your Mac, the same one used by the terminal, VS Code and the app.
  • There when you start your Mac. Tato opens at login and shows the last known values instantly.
  • Mac only, Claude only or both. Turn it off and the button disappears completely.

Tato is independent: not affiliated with or endorsed by Anthropic. The limits come from an internal, undocumented endpoint that may change. You can turn it off at any time in Preferences.

Compatibility

Made for Macs with a Touch Bar.

You need a MacBook Pro with a Touch Bar and macOS 13 Ventura or newer.

MacChipStatus
MacBook Pro 13" (2020)Tested on macOS 27Apple M1TestedAll metrics and Claude mode.
MacBook Pro 13" (2022)Apple M2CompatibleSame sensors and APIs as the M1, not tested yet.
MacBook Pro 13", 15" and 16" (2016 to 2020)IntelPartialTemperature and fan via SMC, not tested. No CPU/GPU frequency. Claude mode works on any Mac.
Macs without a Touch BarAnyNo buttonThere is no Touch Bar. The menu bar panel may work, but it is not the focus.

Tato uses private Apple APIs to pin the button to the Control Strip and read sensors. A macOS update can break something. If it does, the menu shows a warning. Metrics your Mac cannot read disappear on their own.

Install

Ready in a minute.

  1. Download and open

    Download the .zip above, unzip it and drag Tato to Applications. The app is not notarised, so macOS may block the first launch. Run this once in Terminal:

    xattr -cr /Applications/Tato.app

  2. Keep the Control Strip visible

    In System Settings, Keyboard, Touch Bar Settings, choose “App Controls” and keep the Control Strip on. Names vary a little between macOS versions.

  3. Tap the button

    On the right of the Touch Bar, next to brightness and volume, you will find the Tato button. Tap it to open the bar and use the ✕ to close it.

  4. Choose what to show

    Menu bar icon, Preferences: tick, drag to reorder, pick up to 2 values for the button and, if you like, turn on Claude mode.

Prefer to build it? Clone the repository and run make run. You only need the Xcode Command Line Tools.

Privacy and security

Your data stays with you.

The code is open and small, with no third-party libraries, no analytics and no server of its own.

What leaves your Mac

Only two requests: the public status at status.claude.com and, in Claude mode, the limits request to api.anthropic.com with your own login. Nothing goes to the app's author.

The Claude login

Read from the Keychain only with your permission, kept in memory only, and sent solely to Anthropic's address, with no redirects followed and no disk cache. It is never written or logged.

Conversations

Tokens come from the local Claude Code logs, reading only date, model and counts. Conversation text is never read or sent.

No sudo, no background network

No reading needs administrator rights. You can turn Claude mode off, and the request with it, in Preferences.

Frequently asked questions

macOS says the app is damaged or from an unidentified developer.

Tato is free and not notarised by Apple. Run xattr -cr /Applications/Tato.app in Terminal and open it again.

The button does not show on my Touch Bar.

Check System Settings, Keyboard, Touch Bar Settings: the Control Strip must be on and the mode must not be “Expanded Control Strip”. Then reopen Tato.

A metric shows “–” or is missing.

Your Mac cannot read that metric. Run make probe in the repository to see exactly what each sensor returns. GPU temperature also shows “–” while the GPU is idle.

Does it work on Intel or M2 MacBook Pros?

The M2 shares the M1 sensors and APIs, so it should work, but it is untested. Intel is partial: temperature and fan via SMC, no CPU/GPU frequency. Reports are welcome.

Is using the Claude login allowed?

Tato reads your own login, on your own Mac, and queries an internal endpoint that Anthropic does not document. That can change or be restricted at any time, and the choice to use it is yours. It can be turned off.

How do I uninstall it?

Quit Tato, delete it from Applications and, if you enabled it, remove it from System Settings, General, Login Items.
